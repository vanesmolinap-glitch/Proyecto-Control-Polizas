# AGENTS.md

Este repositorio no contiene código fuente. Es un repositorio de documentos de control de pólizas de seguros.

## Estructura

```
Insumos_Control_Polizas/
  Maestro_Clientes.xlsx          # Listado maestro de clientes
  polizas/
    Poliza_AIS-2026-0001.pdf     # Pólizas tipo AIS (2026, 0001-0005)
    Poliza_PCS-2026-0001.pdf     # Pólizas tipo PCS (2026, 0001-0008)
    Poliza_SPC-2026-0001.pdf     # Pólizas tipo SPC (2026, 0001-0007)
```

## Comandos

No hay comandos de build, test, lint, typecheck ni CI. No hay package manager, lockfile ni scripts ejecutables.

## Notas

- Todo el contenido son archivos binarios (PDF y XLSX). No edites directamente sin una aplicación correspondiente.
- No hay convenciones de rama, PR ni release documentadas.
- No hay `opencode.json` ni archivos de instrucción adicionales en el repositorio.
